Multiplikations- und Divisionsmonster

Ein Lernspiel zum kleinen Einmaleins für Mittelschulkinder. Es läuft im Browser auf Tablet, Handy oder Computer, ohne Installation.

Für Kinder: Sie besiegen Monster, indem sie Mal-, Geteilt- und Platzhalteraufgaben (z. B. 7 × ? = 56) schnell lösen. Es gibt vier Welten, Bosse mit Schilden, Combos und eine Tagesmission. Für Erfolge gibt es Kisten, Sammelkarten, Coins, Kleidung für das eigene Monster und einen Monster-Pass. Aufgaben, die noch wackeln, kommen öfter, und bei Fehlern zeigt das Spiel eine Rechenstrategie. Mit einem 8-stelligen Code melden sich die Kinder auf jedem Gerät an und machen dort weiter, wo sie aufgehört haben.

Für Lehrkräfte: Die Anmeldung geht auf jedem Gerät mit Klassenname und Passwort. Du legst die Kinder direkt an und gibst ihnen ihre Codes. Du siehst pro Zahlenreihe, wie oft sie geübt wurde und wie gut sie sitzt, und wer was sicher kann. Einzelnen Kindern gibst du Zusatzzeit oder schaltest Welten frei. Außerdem gibt es einen gemeinsamen Wochen-Boss für die Klasse mit Siegerehrung.

Datenschutz: Gespeichert werden nur Vorname oder Spitzname, Spielfortschritt und Fehlerstatistik, ohne Registrierung und ohne E-Mail-Adresse. Die Klassendaten der Lehrkraft werden mit dem Klassenpasswort verschlüsselt. Bitte kläre den Einsatz vorher mit Schulleitung bzw. Datenschutz.
